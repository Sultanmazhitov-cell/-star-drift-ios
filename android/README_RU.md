Android 8.0 и выше, с актуальным Android System WebView. Относительное управление сохранено: новое касание не переносит ракету к пальцу. Сворачивание ставит полёт на паузу.

## Установить

Скачайте `StarDrift-Android.apk` на Android, откройте файл и подтвердите установку. Если система запросит разрешение на установку из этого источника, выдайте его браузеру или файловому менеджеру, из которого открыли файл. APK предназначен для Android и не устанавливается в iOS.

## Собрать

GitHub Actions → **Build Android APK** → **Run workflow**. Сборка выполняется на Ubuntu с JDK 17, Gradle 8.13 и Android Gradle Plugin 8.13.0. Workflow собирает APK, выполняет Android Lint, проверяет APK-подпись и запускает smoke-тест на эмуляторе Android 15.

Результат: артефакт `StarDrift-Android-APK`, внутри подписанный `StarDrift-Android.apk`. Это debug-сборка для личной установки, не выпуск в Google Play. На разных облачных машинах debug-ключ может отличаться; в таком случае установка следующей версии потребует удаления предыдущей и сбросит локальный рекорд. Для постоянных обновлений или Google Play следует настроить отдельный постоянный ключ релизной подписи.

Без Android Studio можно использовать установленный Gradle 8.13:

```sh
gradle --no-daemon :app:assembleDebug :app:lintDebug
```

Игровые ресурсы скопированы из браузерной версии в `app/src/main/assets/game`; последующие изменения сайта не меняют уже установленный APK.
