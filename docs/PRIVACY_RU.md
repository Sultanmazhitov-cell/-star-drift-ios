# Политика конфиденциальности «Звёздного рейса»

Черновик для размещения перед выпуском. Владелец приложения должен добавить дату действия, своё имя или название организации и публичный способ связи. Текст описывает текущую версию без рекламы, покупок, учётных записей и сторонних SDK; при изменении этих функций политику нужно обновить.

## Какие данные использует приложение

Игра сохраняет рекорд и выбранные настройки на устройстве. Эти данные нужны для продолжения использования приложения с вашими предпочтениями.

Приложение не отправляет рекорд и настройки разработчику, не создаёт учётную запись и не запрашивает имя, адрес электронной почты, местоположение или доступ к контактам, камере и микрофону.

## Передача и отслеживание

В игре нет рекламы, аналитических SDK и отслеживания пользователей. Для игры не требуется интернет. Разработчик не получает персональные данные через приложение и не передаёт их третьим лицам.

## Управление локальными данными

Рекорд и настройки хранятся в локальном хранилище приложения. Удаление приложения удаляет его локальные данные с устройства; они могут восстановиться при восстановлении устройства из резервной копии, если такая копия была создана средствами iOS.

## Вопросы

Способ связи с владельцем приложения нужно добавить до публикации этой политики. Текущий файл является черновиком и не заменяет публичную страницу по URL, указанному в App Store Connect.
