# Реальные снимки iOS

Оригинальные PNG 1320 × 2868 с симулятора iPhone 17 Pro Max из [успешного UI-теста](https://github.com/Sultanmazhitov-cell/-star-drift-ios/actions/runs/40383237327), 26 октября 2026 года.

- `01-ready.png`: начало полёта.
- `02-playing.png`: игровой процесс.
- `03-paused.png`: пауза.
- `04-settings-before.png`: настройки перед переключением звука.
- `05-settings-sound-changed.png`: звук выключен автоматическим тестом; затем тест восстановил настройку.

Это снимки нативного приложения, без обработки и маркетинговых надписей. Перед отправкой в App Store проверить соответствие итоговой подписанной версии и размерам, которые запросит App Store Connect. Снимки iPad пока не подготовлены.
