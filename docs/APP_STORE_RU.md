# Материалы для App Store

Черновик для первой версии: бесплатная игра без рекламы, покупок и регистрации. Тексты нужно сверить с итоговой сборкой перед отправкой.

## Карточка приложения

**Название:** Звёздный рейс

**Подзаголовок:** Лови звёзды. Береги корабль.

**Категория:** Игры → Аркады; дополнительная — Казуальные.

**Ключевые слова:** космос,ракета,звёзды,аркада,корабль,метеориты,реакция,рекорд,офлайн

**Промотекст:** Маленькое космическое приключение: собирай звёзды, обходи метеориты и побей свой рекорд. Бесплатно, без рекламы и интернета.

**Описание:**

Отправляйся в звёздный рейс — короткую космическую аркаду, в которую легко играть одной рукой.

Корабль повторяет движения пальца, поэтому управлять можно в удобном месте экрана, не закрывая ракету. Собирай золотые звёзды, обходи метеориты и постарайся продержаться как можно дольше. У корабля три щита, а полёт постепенно становится сложнее.

- Управление движением пальца без скачков при новом касании.
- Бесконечный полёт и личный рекорд.
- Пауза, звук и тактильный отклик.
- Игра работает без подключения к интернету.
- Без рекламы, встроенных покупок и регистрации.

Каждая звезда — ещё 50 очков. Как далеко ты сможешь улететь?

## Заметки для проверки Apple

This is a native SwiftUI/SpriteKit arcade game. No account, sign-in, purchases, subscription, advertising, or network connection is required. Tap the start button to play. Drag anywhere in the playfield to move the ship by the same relative distance; touching elsewhere does not teleport it. Collect stars and avoid asteroids. The game ends after three hits. Pause and sound controls are available in the game UI. Scores and preferences are stored locally on the device. No demo credentials are needed.

## Что заполнить перед отправкой

- Уникальный Bundle ID и данные владельца приложения.
- Публичный URL поддержки: страница с рабочим способом связи с разработчиком.
- Публичный URL политики конфиденциальности: разместить итоговый текст из `PRIVACY_RU.md`.
- Контакт для команды App Review — в App Store Connect, не в публичном описании.
- Снимки экрана из настоящей iOS-сборки для запрошенных App Store Connect размеров. Изображения сайта не заменяют проверку интерфейса iOS.
- Возрастная анкета, сведения о правах на контент и экспортном соответствии — по итоговому приложению и данным владельца. Ответы не выбирать автоматически от его имени.
- Цена «Бесплатно» и территории доступности.

В разделе App Privacy для текущего приложения без сетевых запросов и сторонних SDK предполагается **Data Not Collected**. Перед отправкой проверить это по итоговому коду и всем добавленным SDK. Локальное хранение рекорда и настроек не означает передачу данных разработчику.

Поле «Что нового» потребуется для последующих обновлений. Сейчас приложение не отправлено на проверку и не опубликовано.
